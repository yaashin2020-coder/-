# 設定（記入して使う）

## noteのアカウント

```
note_username:
```

`https://note.com/<ここ>/` の部分。埋めておくと、URLを貼らずに
「noteを投稿したよ」だけで最新記事を取りに行ける（要ネットワーク許可）。

## 投稿スタイル

好みが固まったらここに書く。書いてある内容がSKILL.mdの既定より優先される。

- 文体（です・ます / だ・である / 口語）:
- 一人称:
- よく使うハッシュタグ:
- 絵文字を使うか:
- 冒頭に付ける定型句（例「新しい記事を書きました」）:
- 避けたい表現:

## 投稿履歴

重複投稿を防ぐため、シェア済み記事のURLをここに追記していく。
