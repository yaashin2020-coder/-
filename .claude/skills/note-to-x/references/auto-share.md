# 完全自動化（GitHub Actions）

スマホでnoteに公開するだけで、Xにも自動で投稿される仕組み。
Claudeのセッションを開く必要も、PCを開く必要もない。

```
[スマホ]  noteに公開
   ↓      （最大35分待つ）
[GitHub Actions]  30分おきにRSSを確認 → 新着を見つける → Xへ投稿
```

## これを使うかどうか

**人の確認を挟まずにXへ投稿される。** それが許容できるかで決める。

| | ワンタップ方式 | 自動投稿（これ） |
|---|---|---|
| 手間 | Claudeに報告してリンクをタップ | **なし** |
| 投稿文 | 記事の要点を含む。毎回変えられる | タイトル＋URLの定型 |
| 誤爆リスク | 送信前に必ず目で見る | 目視なし |
| Xへの反映 | すぐ | 最大35分 |

投稿文が定型になるのは意図的で、記事本文からAIが要約を作ると、
**誰も見ていない場所で事実と違う要約が公開される**危険があるため。
タイトルとURLはRSSの実データなので、その心配がない。

## 設定手順

### 1. noteのユーザー名を登録する

リポジトリの Settings → Secrets and variables → Actions → **Variables** タブ →
New repository variable

- Name: `NOTE_USERNAME`
- Value: `long_whale5827`

### 2. Xの認証情報を登録する

同じ画面の **Secrets** タブ → New repository secret を4回。
値の取り方は `setup.md` のA参照（**アプリ権限を Read and write にしてから
トークンを発行し直すこと**）。

- `X_API_KEY`
- `X_API_SECRET`
- `X_ACCESS_TOKEN`
- `X_ACCESS_TOKEN_SECRET`

### 3. 試運転する

Actions タブ →「note → X 自動投稿」→ Run workflow →
**「投稿せずに内容だけ確認する」にチェックを入れたまま**実行。

ログに投稿予定の文面が出る。実際には投稿されない。
ここで文面と文字数を確認する。

### 4. 本番を有効にする

初回の実行は**必ず初期化だけで終わる**。そのとき存在する記事をすべて
「投稿済み」として記録し、1件も投稿しない。過去記事がまとめてXに流れる
事故を防ぐため。**次に公開した記事から実際に投稿が始まる。**

## 安全装置

無人で動くので、壊れ方を想定した歯止めを入れてある。

- **二重投稿しない** … 投稿済みURLを `.note-to-x-state.json` に記録し、
  リポジトリへコミットする。1件投稿するごとに保存するので、途中で落ちても
  投稿済みの記事を投げ直さない。
- **初回に過去記事を流さない** … 上記のとおり初回は記録だけ。
- **古い記事を拾わない** … 公開から2日以上経った記事は、未投稿でも対象外。
- **1回の実行で最大2件** … RSSが一時的に壊れて全記事が「新着」に見えても、
  大量投稿にならない。
- **同時実行しない** … `concurrency` で直列化する。
- **文字数を超えない** … タイトルが長ければ末尾を詰める。URLは削らない。

## 止め方

Actions タブ →「note → X 自動投稿」→ 右上の `···` → Disable workflow。
すぐに止まる。

## 費用

GitHub Actionsの無料枠内（パブリックリポジトリなら無制限、プライベートでも
1回あたり数十秒なので月2,000分の枠に十分収まる）。
X APIも無料枠（月500投稿）で足りる。
