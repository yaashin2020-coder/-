# スマホからの運用フロー

スマホでnoteに投稿 → そのままXへシェアするまでの手順。
PCを開かず、Claudeアプリとnoteアプリとブラウザだけで完結する。

## 全体像

```
[noteアプリ]  記事を公開
     ↓        共有 → リンクをコピー
[Claudeアプリ] このリポジトリのセッションを開いて貼る
     ↓        Claudeが投稿文＋ワンタップリンクを返す
[Xアプリ]     リンクをタップ → 本文入りの投稿画面 → 送信
```

所要は慣れれば1分弱。**Xへの送信ボタンを押すのは必ず人間**なので、意図しない投稿は起きない。

## セッションの開き方

**特定のセッションを探して復帰しなくてよい。** このスキルは
`yaashin2020-coder/-` の `claude/note-to-x-sharing-ucoocw` ブランチに
コミットされているので、そのリポジトリ・ブランチで新しいセッションを開けば
自動的に読み込まれる。古いセッションが期限切れで消えていても影響しない。

（同じセッションを続ける利点は、過去の投稿文の文体を覚えている点だけ。
文体を固定したいなら `config.md` に書くほうが確実。）

## スマホで打つ内容

これだけ。1メッセージで送る。

```
noteを投稿したよ
https://note.com/long_whale5827/n/xxxxx

・（要点1）
・（要点2）
・（要点3）
```

- **URLは必須。** noteアプリの共有ボタン →「リンクをコピー」で取れる。
- **要点も必須。** URLだけだとClaudeはこの環境からnote.comに到達できず、
  記事の中身を一切知れない。推測で書くことは禁止しているので、投稿文が作れない。
- 本文まるごとコピペでもよいが、スマホでは**箇条書き2〜3行のほうが速い**。
- **音声入力が一番速い。** Claudeアプリの入力欄でマイクを押し、
  「〇〇について書いた。要点は〜」と喋れば十分。誤字は気にしなくてよい。

## 返ってくるもの

```
投稿文（132/280文字）:

〈投稿文の全文〉

ワンタップ投稿: https://x.com/intent/post?text=...
```

- 投稿文の全文が先に出るので、**タップする前に中身を確認できる**。
- リンクをタップするとXアプリが開き、本文が入った状態の投稿画面になる
  （iOS/Androidともユニバーサルリンクで、ブラウザではなくアプリが開く）。
- 直したいところがあれば「もっと短く」「〇〇に触れて」などと返せば作り直す。
  **修正のたびにリンクも新しくなる。古いリンクをタップしないこと。**

## つまずきやすい点

| 症状 | 原因と対処 |
|---|---|
| リンクを開いてもXアプリでなくブラウザが開く | Xアプリ未ログインか、リンクを長押し→「Xで開く」を選ぶ |
| 投稿画面の本文が途中で切れている | 280文字（全角140字）超過。Claudeに「短くして」と言う |
| 文字数が足りているのに投稿できない | 記事URLもXでは23文字扱い。本文を数文字削る |
| Claudeが記事の中身を知らないと言う | 要点を貼っていない。`https://note.com` はこの環境から到達不可 |
| ハッシュタグが `#` ごと消える | 貼り直す。`#` の直前に半角スペースが要る |

## 将来、自動化するなら

`note.com` と `api.x.com` がネットワーク許可リストに入り、Xの認証情報が
設定されれば、`config.md` の `mode` を `auto` にして完全自動化できる
（手順は `setup.md`）。そうなればスマホから「noteを投稿したよ」の一言だけで済む。

ただし**その場合でも投稿前の確認は残す**。取り消しづらい外向きの行為なので、
無人で飛ぶ設定にはしない。
